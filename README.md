# ひっくりかえるのがみえるリバーシ

スマホで遊べる、**ルールを覚えていない子どもでも遊べる**リバーシ（オセロと同じルール）です。
おける マスには「ひっくりかえる石の数」が出て、タッチすると どの石が ひっくりかえるかが光ります。置く前に「置いたらどうなるか」が見えるので、遊びながらルールを覚えられます。

[いきがみえる囲碁（YYigo）](https://github.com/ykwyuta/YYigo) と同じ考え方・同じ構成で作っています。ブラウザだけで動く静的サイトです。ビルドもサーバーも要りません。Cloudflare（Workers の静的アセット配信）でそのまま公開できます。

- 盤の大きさ：6×6（はじめて向け）・8×8（ふつう）・10×10
- CPU 対戦（はじめて／よわい／ふつう／つよい、くろ・しろ・おまかせ）。「はじめて」は半分以上の手を適当に打つので、子どもでも勝てます
- ふたりで対戦（1台のスマホを交互に使う）
- ハンデ：くろが はじめから かどを 1〜4つ もらう
- **さいごの もんだい 30 問**（のこり 4マス 10・6マス 10・8マス 10）。終盤を読み切って勝つ手を見つける問題
- 対局は自動保存。ブラウザを閉じても続きから遊べます
- ホーム画面に追加するとアプリのように全画面で使えます

## 子ども向けのおたすけ機能

| 機能 | 内容 |
| --- | --- |
| おける ところ | おけるマスに ・ と「ひっくりかえる石の数」を表示（せっていで切りかえ）。 |
| おく前に たしかめる | おけるマスをタッチすると、うすい石と、ひっくりかえる石（黄色く光ってゆれる）・はさむ相手の石を表示。何こ かえるか・何方向か・相手が次に何か所おけるか・置いたあとの数を説明。もう一度タッチで置きます（せっていで 1回タッチに変更可）。 |
| かど | 置けるかどに点線の わ。かどを置くと「もう ひっくりかえらない」と説明。 |
| あぶないマーク | 置くと相手にかどを取られるようになるマスに「!」。 |
| かくてい石 | 石をタッチすると、その石が もう ひっくりかえらない（かくてい）かを説明。せっていで かくてい石にしるしを付けることもできます。 |
| パスのお知らせ | 置けるところがないときは自動でパスし、「○○は おけないので パス」と知らせます。 |
| ひっくりかえる アニメーション | 置いた石から近い順に、石がくるっと裏返ります。 |
| ヒント | CPU がおすすめの手を教えてくれます（光ったマスをタッチするだけ）。 |
| まった | 何手でも戻せます。負けた後や こうさんの後でも「まった」で戻ってやり直せます。 |

「ルール」ボタンでは、はじめの並び・はさむ・8方向・おけるところ・パス・おわり・かど・かどのとなり・かくてい石・ハンデを図つきで説明します。

## さいごの もんだい

画面上の「さいごの もんだい」ボタン（またはメニュー）から、30 問の問題集を遊べます。

- くろの番。さいごまで打って、くろの石をしろより多くすれば正解。
- しろは、くろの石がいちばん少なくなる手（いちばん ねばる手）を打ってきます。
- 勝てなくなる手を打つと「ざんねん」。「まった」で戻ってやり直せます。
- 「ヒント」で勝てる手が光ります。「こたえを みる」で正解手順・まちがえやすい手（としろの応手）を見たり、正解手順を盤に並べたりできます。
- クリアした問題には ★ が付き、記録は自動保存されます。

### 問題の作り方と検証

`tools/gen-puzzle.js` でランダムな対局から候補を作り、読み切りソルバー（`js/ai.js` の `AI.Exact`、`js/puzzle.js`）で次の条件を満たすものだけを残して選んでいます。

- くろの番で、くろの置ける手が 3つ以上
- 勝てる手がちょうど 1つ。しろが最善で応じても、そのあとのくろの勝てる手もいつも 1つ
- 問題ごとのしるし（かど・パスさせる・いちばん少なく返す手が正解・いちばん多く返す手はまちがい・いまは負けている）が本当に成り立つ

`node test/puzzle.test.js` で全問を確かめています。

```sh
node tools/gen-puzzle.js 6 20 42 6 > candidates.json   # のこり 6マスの候補を 20 個（seed 42・6×6）
```

## ルール

- くろとしろが交互に、マスに石を置きます。くろが先。
- 自分の石で相手の石を たて・よこ・ななめ にはさむと、はさんだ石がぜんぶ自分の色になります。1つもはさめないマスには置けません。
- 置けるところがないときはパス（自動）。ふたりとも置けなくなったら（盤が埋まったときも）おわり。石の多い方の勝ち。

## Cloudflare で無料公開する

Cloudflare Workers の静的アセット配信を使います。ビルドは不要です。設定はリポジトリに入っている `wrangler.jsonc` / `.assetsignore` / `_headers` だけです。

### 方法 A：GitHub と連携して自動デプロイ（おすすめ）

1. ゲーム本体と `wrangler.jsonc` が入ったブランチを、Cloudflare がビルドする本番ブランチにしておく（このリポジトリの既定ブランチは `master`）。
2. [Cloudflare ダッシュボード](https://dash.cloudflare.com/) → **Workers & Pages** → **作成（Create）** → **リポジトリをインポート（Import a repository）**。
3. GitHub を連携して `YYreversi` を選ぶ。
4. 設定はそのまま（ビルドコマンド：空欄、デプロイコマンド：`npx wrangler deploy`、ルートディレクトリ：`/`）。
5. **デプロイ** を押すと `https://yyreversi.<あなたのサブドメイン>.workers.dev` で公開されます。

### 方法 B：手元のパソコンからコマンドで公開

```sh
npx wrangler login    # 初回のみ
npx wrangler deploy   # 公開（URL が表示される）
```

手元で確認したいときは `npx wrangler dev`（または `python3 -m http.server`）で立ち上げます。

## ファイル構成

```
index.html             画面
css/style.css          見た目（スマホ縦向きを基本に、広い画面では2段組み）
js/rules.js            ルールエンジン（はさむ・ひっくりかえす・自動パス・おわり・ハンデ・かくてい石）
js/ai.js               CPU 思考（アルファベータ探索＋反復深化。制限時間で打ち切り。終盤は読み切り）
js/worker.js           CPU の思考を Web Worker で動かす（画面が固まらない）
js/puzzle.js           さいごの もんだいのソルバー（正解判定・しろの応手・ヒント・まちがえやすい手）
js/puzzle-data.js      さいごの もんだい 30 問
js/ui.js               描画と操作（おたすけ表示・ヒント・まった・保存）
manifest.webmanifest   ホーム画面に追加したときの設定
icons/                 アイコン
test/                  Node.js で動くテスト（公開はされない）
tools/                 問題の生成ツール（公開はされない）
```

ルールエンジンは DOM に依存しない純粋な関数で、`apply` は常に新しい局面を返します。CPU は高速化のため、周りに枠を付けた盤（`AI.FastBoard`）で、裏返した石をスタックに積んで戻しながら探索します（ルールエンジンと同じ結果になることをテストで確認）。

```js
require('./js/rules.js'); require('./js/ai.js');
let s = Engine.newGame({ size: 8 });
s = Engine.apply(s, AI.think({ size: s.size, board: s.board, turn: s.turn }, 'normal'));
console.log(s.kifu); // [ '●d3' ] など
```
